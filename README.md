# Disease-Prediction-and-Medical-Recommendation-System-main

## 📌 Project Overview
The Disease Prediction and Medical Recommendation System is a Python-based web application that predicts possible diseases based on user-provided symptoms and provides relevant medical recommendations.

## 🚀 Features
- User login and registration
- Symptom-based disease prediction
- Machine Learning using Random Forest
- Medical recommendations
- Simple and user-friendly web interface
- Flask-based web application

## 🛠️ Technologies Used
- Python
- Flask
- Machine Learning
- Random Forest
- Pandas
- NumPy
- HTML
- CSS

## 📂 Project Structure
- main.py – Main Flask application
- model/ – Trained machine learning model
- templates/ – HTML pages
- static/ – Images and styling files
